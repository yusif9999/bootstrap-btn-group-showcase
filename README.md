# TechMeet 2026 - Conference Landing Page

A modern, responsive conference landing page built to practice and showcase **Bootstrap 5 Button Groups** and grid layouts. This project serves as a user interface for tech event registration, allowing attendees to view the schedule and select their ticket preferences.

## 🚀 Overview

This project was developed with a strict focus on front-end structuring using HTML5, CSS3, and Bootstrap 5. The primary learning objective of this repository is the effective implementation of **Bootstrap Button Groups** (`.btn-group`, `.btn-toolbar`, radio buttons, and checkbox toggles) to create a seamless ticket selection experience without relying on external JavaScript logic.

## ✨ Key Features

*   **Interactive Ticket Selection:** Utilizes Bootstrap's radio and checkbox button groups for a stylish and accessible ticket purchasing UI (Standard, Student, VIP).
*   **Responsive Layout:** Fully responsive grid system adapting to mobile, tablet, and desktop screens.
*   **Event Schedule Table:** A clean, easy-to-read schedule table customized with Bootstrap table classes (`.table-dark`, `.table-warning`).
*   **Modern Typography & Icons:** Integrated with Bootstrap Icons and FontAwesome for visual hierarchy.

## 🛠️ Technologies Used

*   **HTML5:** Semantic markup and structure.
*   **CSS3:** Custom styling and layout adjustments.
*   **Bootstrap 5 (v5.3.8):** Core framework for UI components, button groups, alerts, and responsive grid.

## 📂 Project Structure

*   `index.html`: The main markup file containing the entire layout and Bootstrap components.
*   `style.css`: Custom stylesheet for specific adjustments (e.g., table styling, image dimensions).
*   `img/`: Directory containing placeholder images for speakers and events.
